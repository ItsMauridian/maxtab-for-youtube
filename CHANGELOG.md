# Changelog

## 0.1.2

- Renamed the extension to **MaxTab for YouTube**.
- Added a Firefox `.xpi` release asset alongside the ZIP package.
- Improved hidden-tab pause-event handling to avoid misclassifying a near-simultaneous manual pause.
- Added deterministic release hashes and publication metadata.

## 0.1.1

- Added the Firefox `.xpi` package and clarified temporary installation instructions.
- Added desktop browser targeting documentation and Firefox Android scope limits.

## 0.1.0

- Initial independent MIT-licensed release.
- Highest available YouTube quality selection.
- Hidden-tab pause and controlled resume behavior.
