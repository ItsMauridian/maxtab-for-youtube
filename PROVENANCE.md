# Provenance statement

The implementation is an independent rewrite created from the requested behavior and public WebExtension, HTML media, and YouTube player observations.

The original extension was inspected before this rewrite to understand the requested behavior and identify browser-policy constraints. No source expression, assets, translations, tests, or custom license text from ImprovedTube was copied into this project. This project has its own implementation, tests, manifests, documentation, generated icons, and MIT License. This is not a claim of a double-blind development process.

Future contributors must preserve this boundary. If a contribution is adapted from another project, record the source, license, exact files, and compatibility rationale before merging it.
